================================================================================
  HYBRID RAG FOR CODEBASES — PROJECT COMMAND REFERENCE
  Quick guide to run, test, and analyze
================================================================================

1. ENVIRONMENT SETUP
--------------------------------------------------------------------------------
# Activate the virtual environment (Run this every time you start a new terminal)
.\venv\Scripts\activate

# Update/Install dependencies
pip install -r requirements.txt


2. AST PARSER (src/ast_parser/parser.py)
--------------------------------------------------------------------------------
# Test on a single file (prints tables to terminal)
python src\ast_parser\parser.py data\repos\geoencrypt-pro\backend.py
python src\ast_parser\parser.py data\repos\flask\src\flask\app.py

# Run on an entire repository (saves results to results/ast_parse_output.json)
python src\ast_parser\parser.py data\repos\geoencrypt-pro
python src\ast_parser\parser.py data\repos\flask\src\flask

# VISUALIZE RAW AST (Prints the full tree for one file)
python src\ast_parser\visualize_ast.py data\repos\geoencrypt-pro\backend.py


3. DEPENDENCY GRAPH (src/graph/builder.py)
--------------------------------------------------------------------------------
# Build the graph and run impact analysis
# (NOTE: Run the parser on the repo first to generate the necessary JSON data)
python src\graph\builder.py

# Generate a PNG visualization of the graph
python src\graph\visualizer.py

# To change which function you are analyzing for impact:
# Edit the 'target' variable at the bottom of src/graph/builder.py


4. SEMANTIC VECTOR INDEX (src/vector/index_builder.py)
--------------------------------------------------------------------------------
# Build the vector index (chunks code + generates embeddings)
# (NOTE: Requires OPENAI_API_KEY in .env)
python src\vector\index_builder.py


5. SEMANTIC SEARCH (src/retrieval/searcher.py)
--------------------------------------------------------------------------------
# Run a natural language query against the codebase
python src\retrieval\searcher.py "How is the GPS hash generated?"
python src\retrieval\searcher.py "What functions handle base64?" --num 2


6. FULL RAG PIPELINE (src/rag/pipeline.py)
--------------------------------------------------------------------------------
# Ask a complex question and get a grounded answer from the LLM
python src\rag\pipeline.py "Explain the encryption flow in backend.py"
python src\rag\pipeline.py "How does the haversine formula work here?"


7. OUTPUT FILES
--------------------------------------------------------------------------------
- results/ast_parse_output.json      -> Raw extracted data (functions, classes, etc.)
- results/dependency_graph.graphml   -> The full graph
- data/chroma_db/                   -> The persistent vector database
